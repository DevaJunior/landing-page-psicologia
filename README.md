# Psychologist Landing Page

Uma landing page moderna, responsiva e de alta conversão, desenvolvida especificamente para profissionais da área da saúde e psicologia.

[Link para o projeto online - link do Vercel]

---

## 🚀 Funcionalidades e Foco em UX

* **Design Orientado à Conversão:** Chamadas para ação (CTAs) estratégicas direcionando para agendamento via WhatsApp ou formulário de contato.
* **Totalmente Responsivo:** Experiência fluida e adaptada para dispositivos móveis, tablets e desktops (Mobile-First approach).
* **Navegação Suave (Smooth Scrolling):** Links âncora que deslizam suavemente entre as seções (Sobre, Especialidades, Depoimentos, Contato).
* **Performance Otimizada:** Carregamento rápido de imagens e assets estáticos para garantir uma boa pontuação de SEO e retenção de usuários.

---

## 💻 Tecnologias e Arquitetura

Este projeto demonstra a capacidade de traduzir layouts visuais em código limpo e performático:

* **React 18:** Componentização da interface para facilitar a manutenção das seções da página.
* **Vite:** Ferramenta de build para garantir um bundle leve e carregamento instantâneo no ambiente de desenvolvimento.
* **CSS / Estilização:** Uso de propriedades customizadas (variáveis) e Flexbox/Grid para layouts complexos sem dependência excessiva de frameworks pesados.
* **Ícones e Assets:** Integração otimizada de vetores (SVGs) para manter a qualidade visual em qualquer resolução.
